# SD 플리마켓 PC Prototype 1

물류센터처럼 별도 앱으로 개발한 뒤 기능이 완성되면 SD종합센터 확장팩으로 출시하기 위한 개발용 프로젝트입니다.

## 현재 구현 범위

- 폐창고 회수 임무
  - WASD 이동
  - 가까운 수색 지점에서 E 키로 조사
  - 임무당 최대 상자 3개
- 상자 등급
  - 낡은 상자 55%
  - 평범한 상자 29%
  - 고급진 상자 11%
  - 최고급 상자 3%
  - 금고 2%
- 별도 상자 보관함
- 장비 상점
  - 커터칼 100,000원 / 영구
  - 락픽 10,000원 / 개당
- 일반 상자 개봉
  1. 첫 옆면 절단
  2. 상자를 반대로 돌림
  3. 반대 옆면 절단
  4. 상자를 위로 돌림
  5. 상단 절단
- 금고 개봉
  - 락픽 각도 조절
  - 실린더 회전량으로 정답 각도 탐색
  - 잘못된 각도에서 힘을 주면 락픽 내구도 감소 및 파손
- 등급별 아이템 랜덤 획득
- 개발용 로컬 아이템 보관함

## 개발용 경제

현재 버전은 실제 SD지갑을 건드리지 않도록 로컬 테스트 잔액 500,000원을 사용합니다.
정식 출시 전 단계에서 구매/아이템 지급을 서버 또는 SD지갑의 검증된 거래 API로 교체합니다.

## 실행

```bash
npm install
npm start
```

PC 설치 방법

Windows에서는 설치 프로그램을 내려받아 일반 프로그램처럼 설치합니다.

  1. 1
    홈페이지에서 Windows 다운로드아래의 설치 파일 받기 버튼을 누릅니다.
  2. 2
    다운로드 완료 확인브라우저 다운로드 목록 또는 Windows의 다운로드 폴더를 엽니다.
  3. 3
    SDCenterSetup.exe 실행다운로드한 SDCenterSetup.exe를 더블클릭합니다.
  4. 4
    설치 진행화면 안내에 따라 설치를 완료합니다.
  5. 5
    SD종합센터 실행설치가 끝나면 시작 메뉴 또는 바탕화면에서 SD종합센터를 실행합니다.

삼성 갤럭시 설치 방법

갤럭시는 Android APK를 내려받아 SD종합센터 앱으로 설치할 수 있습니다.

  1. 1
    Chrome 또는 삼성 인터넷으로 접속휴대폰에서 현재 SD종합센터 홈페이지를 엽니다.
  2. 2
    Android 앱 설치하기 선택APK 다운로드 버튼을 눌러 설치 파일을 받습니다.
  3. 3
    다운로드한 APK 열기다운로드 알림을 누르거나 내 파일 → 다운로드에서 APK를 엽니다.
  4. 4
    처음 한 번 설치 권한 허용브라우저에서 받은 앱 설치 권한을 요청하면 해당 브라우저에 대해서만 허용합니다.
  5. 5
    설치 버튼 누르기Android 설치 화면에서 설치를 누르고 완료될 때까지 기다립니다.
  6. 6
    앱 실행 및 로그인홈 화면의 SD종합센터를 열고 홈페이지 계정으로 로그인합니다.

iPhone 설치 방법

iPhone은 APK를 설치하지 않고 Safari에서 홈페이지를 홈 화면에 추가해 앱처럼 사용합니다.

  1. 1
    Safari로 홈페이지 접속iPhone의 Safari에서 SD종합센터 홈페이지를 엽니다.
  2. 2
    공유 버튼 누르기Safari의 공유 버튼을 눌러 메뉴를 엽니다.
  3. 3
    홈 화면에 추가 선택메뉴에서 홈 화면에 추가를 찾아 선택합니다.
  4. 4
    추가 확인이름이 SD종합센터인지 확인한 뒤 추가를 누릅니다.
  5. 5
    홈 화면 아이콘으로 실행이후에는 홈 화면에 생긴 SD종합센터 아이콘을 눌러 실행합니다.

HELP

자주 묻는 질문

확장팩은 어떻게 설치하나요?

확장팩 ZIP을 다운로드하고 압축을 풀지 않은 상태로 SD종합센터의 ZIP 앱 추가 버튼에서 선택하세요. 같은 확장팩의 새 버전을 선택하면 업데이트할 수 있습니다.

확장팩만 받아도 실행할 수 있나요?

홈페이지의 확장팩은 SD종합센터 추가용으로 배포됩니다. 일부 앱은 개발 환경에서 따로 실행할 수 있지만, 일반 사용자는 종합센터에서 설치하는 방식을 권장합니다.

다운로드 버튼을 누르면 바로 설치 마법사가 열리나요?

브라우저 보안상 홈페이지가 설치 프로그램을 자동 실행할 수는 없습니다. 버튼을 누르면 설치 파일이 다운로드되고, 사용자가 그 파일을 한 번 열면 Windows 설치가 시작됩니다.

Windows에서 알 수 없는 게시자 경고가 나올 수 있나요?

코드 서명 인증서를 적용하지 않은 초기 배포본은 Windows에서 게시자를 확인할 수 없다는 경고가 표시될 수 있습니다. 정식 공개 배포 시에는 코드 서명을 권장합니다.

업데이트하면 기존 데이터가 사라지나요?

앱 데이터는 설치 폴더와 분리된 사용자 데이터 폴더에 저장하도록 구성되어 있습니다. 그래도 중요한 배포 전에는 테스트 PC에서 업데이트와 삭제 동작을 확인하세요.

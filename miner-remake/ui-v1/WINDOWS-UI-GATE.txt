SD광부 4막 5장 Windows UI Gate 확인 순서

1. Windows 설정 > 시스템 > 디스플레이 > 배율을 100%로 설정합니다.
2. RUN-WINDOWS-UI-GATE.cmd를 실행합니다.
3. 작업장 화면과 광산 화면에서 아래 항목을 확인합니다.
   - 잘림 없음
   - 겹침 없음
   - 비정상 가로 스크롤 없음
   - 버튼 밀림/화면 밖 이탈 없음
   - 긴 장비/광물 이름으로 레이아웃 파손 없음
   - 상태/오류 영역이 원문 SQL/stack trace를 노출하지 않음
4. 창을 닫고 Windows 배율을 125%로 바꾼 뒤 2~3을 반복합니다.
5. 창을 닫고 Windows 배율을 150%로 바꾼 뒤 2~3을 반복합니다.

세 배율 모두 정상일 때만 사용자 시각 Gate PASS로 기록합니다.
이 후보는 ?demo=1 로컬 UI 전용이며 Core/지갑/경제 데이터를 읽거나 수정하지 않습니다.

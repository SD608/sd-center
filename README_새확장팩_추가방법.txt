새 확장팩을 홈페이지에 추가하는 방법

1. 확장팩 ZIP을 downloads/extensions 폴더에 넣습니다.
2. assets/js/extensions-data.js를 메모장으로 엽니다.
3. 기존 SD슬롯 항목을 복사해 쉼표로 구분하여 아래에 붙여 넣습니다.
4. 이름, Stage, 버전, 아이콘, 파일명, 설명, 필요 버전을 바꿉니다.
5. 확장팩 아이콘 PNG는 assets/icons 폴더에 넣습니다.
6. 변경한 홈페이지 파일을 GitHub 저장소에 업로드합니다.

중요
- downloadUrl은 downloads/extensions/파일이름.zip 형식으로 작성합니다.
- ZIP 파일 이름과 extensions-data.js의 fileName 및 downloadUrl이 정확히 같아야 합니다.
- 모든 확장팩은 실제 금융 기능이 아닌 가상 시뮬레이션 앱이어야 합니다.
